# GiveFlow — Donation Management System

A simple React project based on the structure of the book-library reference.
Built with JSX (JavaScript + HTML), plain CSS, React Router, and Supabase.

## Open and run in VS Code

1. Open VS Code → File → Open Folder → Documents → WAD1.
2. Click Terminal → New Terminal.
3. Run `npm run dev`.
4. Open http://127.0.0.1:5175/ and keep the terminal running.

Dependencies are already installed on this Mac. On another computer, run
`npm install` once first. Node.js 22.12 or newer is needed by Vite.
If port 5175 is busy, the app may already be running: open the link above.

## Where to edit

```
src/
  components/Navbar.jsx      Navigation links and logo
  pages/Home.jsx             Home page, totals and featured campaigns
  pages/Campaigns.jsx        View, search, add and edit campaigns
  pages/Donors.jsx           View, search, add and edit donors
  pages/Donate.jsx           Save a donation to Supabase
  pages/DonationHistory.jsx  Contribution history and payment updates
  App.jsx                    Routes between the pages
  App.css                    Layout, neon theme, responsive styles
  index.css                  Fonts and base colors
  main.jsx                   Starts React
  supabase.js                Your Supabase URL and public key
public/favicon.svg           Browser tab icon
index.html                   Main HTML file and browser tab title
package.json                 Dependencies and run commands
vite.config.js               React development tool settings
eslint.config.js             JavaScript code checks
```

Save with Command + S. The website updates automatically.
`node_modules` contains installed libraries; you do not need to edit it.
`dist` is generated by `npm run build`; you do not need to edit it either.

## Database

Project: donation management (koudxkytqxojgbojvvnj).
Your URL and publishable key are already in `src/supabase.js`, like the reference.
There are no environment files, login screens, local demo mode, or extra keys.
All displayed records are read directly from Supabase. Save buttons write to
Supabase and report success only after the database confirms the write.

- donors: donor names and emails
- campaigns: campaign descriptions, goals, category, date and status
- donations: donor/campaign links, amount, method, date, status and notes

A donor and a campaign can each have many donations (one-to-many relationships).
Only completed donations count toward received totals and campaign progress.
Pending donations can be marked received on the History page.
This records contributions; it does not process real payments.

The database is already set up with 6 fictional donors, 4 campaigns, and
12 contributions. `database.sql` contains the full schema and seed data.
**Do not run it again unless you want to delete and replace those three tables.**

As requested, this is a no-login classroom demo with public read/write access.
Use fictional information only. The public key is meant for frontend code;
never put a service-role key or database password here.

To see a new donation in Supabase: Table Editor → public → donations → Refresh.

## Demonstration

1. Donors → Add donor → Save donor.
2. Campaigns → New campaign → Save campaign (or use an existing one).
3. Record donation → choose a donor/campaign → enter an amount → Save donation.
4. History → inspect the contribution; filter by donor.
5. Open the Supabase donations table and refresh to see the saved row.
